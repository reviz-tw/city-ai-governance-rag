# 個人研究對話

本站研究對話以 Google subject 作為擁有者，儲存在持久 PostgreSQL（本機為 SQLite）。管理員角色不授予讀取其他人的對話。停用帳號阻止後续存取。

前端首次提問建立 session，再使用 `session_id` 呼叫 `/api/chat/stream`。後端保存問題、回答、引用來源與版本及完成狀態，並從資料庫組合脈絡；有 session 時忽略前端自行提供的 context。歷史選單可還原、重新命名、刪除。新增／重新開始保留舊對話。瀏覽器只保存本人上次選取的 session ID，換裝置沒有選取紀錄時開啟最近對話。

`chat_sessions` 保存擁有者、標題、城市、更新時間與生成租約；`chat_turns` 保存每輪問題、回答、引用及狀態；`chat_summaries` 保存不可覆寫的摘要版本、涵蓋至哪輪、原始輪次 ID、時間及生成方法／模型。既有資料庫由 `store.initialize()` 增加三張新表。

摘要保留最近三輪完整對話，將較早已完成的輪次併入滾動摘要。更新只使用上一版摘要與新納入的原始輪次；失敗或中斷回答不進入摘要。每版摘要在介面中可展開其原始對話。摘要模型失敗時保存有標示的原文摘錄版本；完整訊息不刪除。模型輸入仍受既有長度預算限制，摘要／長訊息可能被截短，模型摘要也應視為脈絡而非事實證據。

完整回答在送出 SSE done 前提交；串流中約每兩秒保存部分回答。斷線收尾保存 interrupted 狀態；程序意外終止以最後 checkpoint 為準。生成租約為十分鐘，事件會續期，過期後可重新提問，舊輪次標為 interrupted。生成中拒絕同對話另一提問與刪除；舊生成結果不覆寫新輪次。刪除對話連同訊息與摘要，不刪除原始文件或既有產出。

API：`POST/GET /api/sessions`、`GET/PATCH/DELETE /api/sessions/{id}`。MCP 的外部聊天仍不自動匯入或讀取；本次只實作本站對話保存與還原。
